# Construction フェーズガードレール

## 実装完全性

- 説明のないプレースホルダーを残さず、ビルド可能な変更を作成する。
- 外部境界の失敗を処理する。
- Unity アセット変更では対応する `.meta` を含め、既存 GUID とシリアライズ参照を保護する。
- Unity が生成する `.csproj`、`.sln`、キャッシュ、ビルド成果物は成果物として編集・コミットしない。
- `Assets/UnityChan/` の変更は、承認された Unit の対象である場合に限定する。

## テスト基準

- 承認済み計画にテスト、または理由を明示した代替検証を含める。
- 未実行の検証は未実行として記録し、成功としない。
- ロジックは可能な範囲で Unity Test Framework の EditMode/PlayMode テストで検証する。
- シーン、Prefab、入力、レンダリングは、必要に応じて Editor と対象ビルドの双方で手動確認し、Unity バージョンと手順を記録する。
- ビルド検証前に Build Settings のシーン参照切れを確認する。

## レビュー基準

- `.unity`、`.prefab`、`.asset` の大きな YAML 差分は、意図したオブジェクト・コンポーネント変更と一致するか確認する。
- コンソールのコンパイルエラー、Missing Script、欠落参照を未確認のまま完了扱いにしない。
