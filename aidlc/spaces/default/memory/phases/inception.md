# Inception フェーズガードレール

## 要求品質

- 各要求に安定 ID と合否判定基準を割り当てる。
- 曖昧な品質表現を測定可能な閾値に置き換える。
- Unity Editor バージョン、対象プラットフォーム、入力デバイス、解像度、フレームレート要件を必要に応じて明示する。

## アーキテクチャ基準

- 重要な決定を Context、Decision、Consequences、Alternatives Rejected とともに記録する。
- プロジェクト固有コードと `Assets/UnityChan/` の同梱コードの責務を分ける。
- シーン、Prefab、ScriptableObject、Input Actions 間のシリアライズ参照を設計上の契約として扱う。

## トレーサビリティ

- すべての要求を、情報源と下流の実現物へ追跡できるようにする。
- シーンや Prefab に関わる要求は対象アセットパスと検証手順まで追跡する。
- brownfield の CodeKB を生成する場合は、9 成果物を揃えるか、部分調査であることと調査済みパスを明記する。

## フェーズ出口

- Build Settings の有効シーンが実在すること、または不整合が既知リスクとして計画に含まれることを確認する。
- pre-release/preview パッケージを利用する機能では互換性リスクと代替策を記録する。
