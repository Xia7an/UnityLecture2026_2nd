# Operation フェーズガードレール

## 配布

- 対象プラットフォーム、Unity バージョン、ビルド識別子、配布先、ロールバック、スモークテスト手順を記録する。
- Build Settings の全有効シーンが実在し、意図した順序で含まれることをビルド前に確認する。
- 対象プラットフォームと配布経路は現在未確認であるため、合意前に仮定しない。

## 可観測性

- 秘密情報を漏らさず、測定可能な正常・失敗シグナルを定義する。
- クラッシュ、シーン遷移失敗、入力不能、重大な描画崩れをスモークテストの観測対象に含める。

## インシデント対応

- 実行可能な復旧方法とエスカレーション条件を定める。
- 前バージョンの再配布または変更の取り消し手順を、配布方法に合わせて準備する。
